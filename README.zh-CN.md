# DSH Bing 每日壁纸

简体中文 · [English](README.md)

为 DSH Web 添加每日 Bing 壁纸、从图片提取的主题色，以及自动日夜外观。独立插件，不修改 DSH 本体。

![DSH Web 中的 Bing 每日壁纸设置示例：壁纸预览、来源选择及图片取色风格](<assets/settings-preview.png>)

## 特性

- 国内（中国）与国际（美国）Bing 来源，支持选择 1080p、2K（2560×1440）和 4K UHD（3840×2160）拉取分辨率，缓存独立，失败时不自动混用其他来源。
- 十种取色风格：M3 Content、M3 Tonal Spot、M3 Fruit Salad、M3 Rainbow、M3 Monochrome、Vibrant、Faithful、Soft、Dysfunctional、Muted。
- M3 风格从图片颜色中评分选择源色；五种自定义风格聚类提取多个候选色，并按风格选择。算法参考 Noctalia，并针对浏览器采样、候选色选择和 DSH 可读性做了调整，结果不保证逐像素一致。
- 平铺配色卡片，日夜预览以斜线分隔，点击即可切换。
- 壁纸可见度按 10%–100% 线性调节，不强制叠加阅读蒙层；图标及语义状态色不重新染色。
- 支持模糊（Blur）、毛玻璃（模糊加雾面）、蓝色调、黑白和压暗滤镜，可分别调节强度并实时作用于背景；设置页预览和主题色提取使用原图。
- 可选 3D 深度视差（WebGL 连续深度形变、Catmull-Rom 双三次放大与 WebGL2 三线性 mipmap），主背景与壁纸侧栏同步渲染，通过单个 `0–100%` 滑块调节强度（`0` 表示关闭）；默认零运行时依赖，在 DSH profile 中选装 `@huggingface/transformers` 后自动启用，并遵循系统“减少动态效果”设置。
- 主页面、侧栏及启动占位页均使用独立的壁纸滤镜层和纯色兜底；页面内容、文档图片和图表不受背景滤镜影响。
- 左右侧栏可独立选择壁纸或主题纯色，可见度和滤镜可跟随主背景或单独调节，并可设置控制条背景是否跟随侧栏。可见度跟随主背景时，侧栏设置默认收起。壁纸与中间区域共用视口坐标，缩放、分栏及抽屉动画中保持连续；纯色和“叠加主题色”均使用下方配色示例的侧栏色，叠色强度独立于壁纸可见度，可独立关闭。桌面与移动端共用设置。
- 支持定时、跟随系统、跟随 DSH，以及固定浅色或深色。默认按浏览器本地时间在 07:00–19:00 使用浅色。
- 标题、日期、来源与版权叠放在图片底部，右上角提供刷新图标。
- 自动检查更新，失败保留上一张图片；界面支持中英文。

## 安装

需要 DSH `>=0.2.2-rc.4 <0.3.0`。

在 DSH 插件管理中安装 **`@nzlov/dsh-bing-wallpaper`**，或让 DSH Agent 安装该 npm bundle。npm 包已预构建，无需手动构建。安装会影响当前 profile 的所有会话。

如需从源码安装（需要 Git、Node.js 和 npm）：

```sh
git clone https://github.com/nzlov/dsh-bing-wallpaper.git
cd dsh-bing-wallpaper
npm ci --ignore-scripts
npm run build
```

随后在 DSH 中使用本目录的绝对路径安装。

启用后打开 **设置 → Bing 每日壁纸**。修改源码后需重新构建；更新已安装的插件时，按插件管理器提示决定是否重启。

### 可选 3D 深度视差

深度视差为选装能力，插件默认保持零运行时依赖。如需启用，请在对应 DSH profile 中安装 `@huggingface/transformers` 并重启 DSH：

```sh
dsh plugin --profile web add @huggingface/transformers
```

安装后，设置页中的 **深度视差** 滑块（`0–100%`，`0` 表示关闭）会自动启用，深度模型会在首次使用时按需下载并缓存至 `~/.cache/dsh-bing-wallpaper`。未安装该依赖时不会下载模型，滑块默认禁用并附小字说明。

## 天气效果

在 **设置 → Bing 每日壁纸** 中打开 **天气选择**，可选择 **关闭**、**跟随位置**，也可以直接选择 **多云**、**大雨**等窗景。选中的窗景立即生效。跟随位置时，填写城市名或“纬度, 经度”，也可以点 **使用当前位置**。选择服务商后点 **应用并查询天气**，设置会显示匹配的地点和天气。

所有天气效果共用一个 Three.js 渲染器。云团和薄雾随风移动，雨雪通过 `InstancedMesh` 批量绘制，小、中、大雨雪主要通过同屏密度区分，每档都有大小各异的粒子，大颗粒下落更快。雨滴打到玻璃后溅开，滴头折射当前壁纸，滑过后留下逐渐消散的湿痕。雪花会短暂附着、融化，窗缘也会出现霜花。雨中偶尔出现分叉闪电，雨势越强越容易触发。

主背景与壁纸侧栏显示同一帧。壁纸可见度只调节天气下方的照片，设置页预览显示原图。场景使用 WebGL2，浏览器无法创建上下文时保留壁纸。硬件加速时，动态天气按绘制耗时调整特效分辨率和帧率。检测到软件渲染时，动画使用较低分辨率并降低刷新频率。切到后台时暂停绘制，开启系统的「减少动态效果」后保持静态。

在 **面向方向** 中选择东、西、南、北，默认朝南。日月光按电脑本地时间模拟从东向西的弧线，06:00 至 18:00 为日光，其余时间为月光。晴天迎光时，暖色光束会缓慢移动。多云时，飘过的云团会遮住部分光束，阳光从云隙间透出。

内置 [Open-Meteo](https://open-meteo.com/) 和 [wttr.in](https://github.com/chubin/wttr.in)。在「跟随位置」模式下填写 **更新间隔（分钟）**，点 **应用并查询天气** 保存。浏览器直接向所选服务发送地点，查询成功后按设定间隔更新，默认 30 分钟，最短 1 分钟。Open-Meteo 按城市名查询时，先使用它的地理编码服务。仅「跟随位置」模式会查询天气。服务商返回的风速和来风方向会按窗景朝向换算，影响雨雪、云雾和玻璃水珠的移动。直接选择窗景时使用基础动画。自定义接口只有风速时，沿用默认向左的风。

自定义服务填写支持浏览器跨域请求（CORS）的 HTTPS 接口。浏览器发送 GET 请求并添加 `location` 参数，例如 `?location=Shanghai`。接口应返回形如 `{"current":{"weather_code":61,"wind_speed_10m":18,"wind_direction_10m":90}}` 的 JSON，其中 `weather_code` 是 [WMO 天气代码](https://open-meteo.com/en/docs#weather_variable_documentation)。可选的 `wind_speed_10m` 单位为 km/h，`wind_direction_10m` 是来风方向，以北为 0° 顺时针计量，90° 表示东风。

## 使用须知

- 无需 API Key 或 CDN。壁纸源仅访问固定 Bing HTTPS 接口，不向 Bing 发送聊天内容或浏览器凭据。
- 图片仅缓存在内存，不提供离线壁纸库。服务端按小时缓存，因此点击刷新不一定下载新图；两个地区也可能展示同一张照片。
- 插件控制项保存在当前浏览器，DSH 的外观偏好则由整个 profile 共享。建议仅在一个主要浏览器启用定时切换，避免不同时间表互相覆盖。
